# Actual invariant register

P01 canonical privacy: any arbitrary query/fragment must yield the same HTTPS apex canonical. Oracle is the fixed approved root, independent of the implementation. Fast-check generates Unicode query/fragment strings. A mutant returning raw URL.href must fail. Regression: email/UTM query and section fragment. No user input or provider data participates.

P02 production identity: only the exact approved HTTPS apex with no credentials/port/query/path is accepted. Foreign .invalid labels, old/corrected-away/preview/lookalike hosts are rejected. Oracle is the literal approved origin. Fault: suffix-host matching. Positive: apex and a trailing slash. Negative: localhost/www/.net/copied domain.

P03 fictional rules: ten unique synthetic fixtures; all outcomes belong to allow/review/action; missing-context cases always require review; criticism/complaints remain allowed. Oracle is the published fixture policy. Generate fixture indexes/modes and repeated operations; clone before each run to observe no mutation. Fault: ambiguous case returns allow. A hundred runs are sampling, not exhaustive proof.

P04 routing scope: any sequence of social/CMS/API choices has moderaty=false. Oracle is YouTube-only product scope. Fault: default product recommendation. No state persists between runs.

Browser invariants: changing modes/presets updates an announced text result; reset restores defaults; keyboard skip/navigation works; no-JS retains all fixtures/checklist; repeated interactions cause no external requests or storage; 320/375/768/1280 layouts do not overflow. Test actual built output.

Replay: FC_NUM_RUNS is a positive safe integer, FC_SEED is signed 32-bit and FC_PATH requires a seed. Replay only the failing test with node --test --test-name-pattern='<exact property name>' tests/actual-contracts.pbt.test.mjs.

Exact-head evidence and limitations are in docs/verification.md and docs/bootstrap.md. The deterministic/property and DOM tests establish their source contracts. They do not establish real provider behavior, a deployed public host, indexing or calibrated AI accuracy.

P05 hosting: Docker context includes only source inputs and runtime receives only static output/config. Nginx has no SPA homepage fallback, uses nonroot writable temp paths and repeats security headers where inheritance changes. Header generation hashes the exact root and 404 inline script bytes without unsafe-inline; a distinct 404-script fixture produced a failing test before correction. Separate published-head CI verified the real Docker build, Nginx syntax, image health and isolated HTTP delivery. Source assertions alone do not establish those runtime results or future Coolify proxy/TLS behavior.
