## Origin, slash, status and redirect policy

- Intended canonical origin is https://aicommentmoderation.com, with base path /, Astro trailingSlash: always and directory output
- Preview serves through loopback at ports 4321 or 4531; its canonical remains the intended apex and its indexing gate is off
- Only the root canonical enters the sitemap. Query strings and fragments never enter canonical metadata, collection or stored state
- No retired-domain migration exists. Public HTTP-to-HTTPS and optional www-to-apex redirects are pending operator decisions and actual one-hop status/location evidence
- Nginx has no blanket homepage fallback. Its internal 404 preserves status, error CSP, noindex and no-store
- Existing documents/media revalidate; existing fingerprinted assets cache immutably. Missing assets must use the error cache policy, not a cached successful homepage
- The container receives internal HTTP on 8080 and does not infer public HTTPS from that connection. Actual Coolify trusted proxy/TLS/DNS/headers/cache behavior is pending

## Access and data boundaries

No admin, authenticated preview, contact, analytics, search, account or external-write endpoint is selected. Exact canonical-origin validation is a build contract; it is not a CSRF control for an absent endpoint. No submitted payload, secret or runtime private configuration enters these files. An externally exposed preview needs approved access protection; noindex/robots are not access control. No external preview or public release has been created.

Automated browser and isolated container evidence for the published baseline are in docs/verification.md. This local alignment and the future deployed host require their own evidence.
